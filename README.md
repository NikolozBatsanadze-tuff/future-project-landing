# Future Project - Landing Page

თანამედროვე, ადაპტური Landing Page, შექმნილი AI-ს დახმარებით.

## 🚀 პროექტის აღწერა
პროექტი შედგება შემდეგი სექციებისგან:
- **Navigation Bar**: ფიქსირებული ნავიგაცია გლუვი სქროლით.
- **Hero Section**: მთავარი სათაური, AI Core ბარათი და CTA ღილაკი.
- **About Section**: პროექტის ძირითადი სტატისტიკა და აღწერა.
- **Features Section**: 3 ბარათიანი Grid განლაგება ინდივიდუალური იკონებით.
- **Contact Section**: ფორმა ვალიდაციითა და JS დამუშავებით.
- **Footer**: საავტორო უფლებები და სოციალური ბმულები.

## 🛠 გამოყენებული ტექნოლოგიები
- **HTML**: სემანტიკური სტრუქტურა
- **CSS**: Responsive Grid, Flexbox, CSS ცვლადები
- **JavaScript (Vanilla)**: ფორმის ინტერაქტიული დამუშავება
